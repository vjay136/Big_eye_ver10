# Big Eye 1.0.0 · Release 1

Preview release of the web and Chrome extension foundation.

## Included

- Existing working Vite frontend and Supabase function sources.
- Local message/URL triage, .eml import, JSON reports and attachment SHA-256 fingerprints.
- Integration Readiness dashboard and the 80+ API verification inventory.
- Email provider hints with distinct unknown account-age fields.
- Optional MX, SPF and DMARC evidence using Google Public DNS.
- Manifest V3 extension using the same triage engine.
- Versioned source, web and extension packages with checksums.

## Pending
