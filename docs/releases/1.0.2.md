# Big Eye v1.0.2 · Release 3

Preview update dated 27 November 2026.

- Separate workspaces for Email, Domains & IP, Links, Attachments, Inventory and Setup.
- Local message, header, URL and attachment checks. The existing Manifest V3 extension keeps its local analysis workflow.
- Free Google and Cloudflare DNS queries for mail records and optional DKIM.
- Keyless NIST product identifier lookup, subject to the upstream public rate limit.
- New Supabase public Auth configuration and 83-entry registry with category filters.

The catalog records integrations rather than asserting that every service is active. Some entries are data formats, local applications or customer-hosted services. Paid plans, licensing restrictions and provider quotas apply independently. The [Google Safe Browsing terms](https://developers.google.com/safe-browsing/terms) restrict commercial use. Provider keys belong in the backend secret store.

The new Supabase project's public Auth settings and JWKS returned HTTP 200. Its provider catalog function returned HTTP 404. The saved management identity returned HTTP 403 when listing functions. Deployment of database migrations and reviewed legacy functions, Auth redirect configuration, and end-to-end account sign-in remain pending project access.

Sources for the new keyless tools are the [NIST CPE product API](https://nvd.nist.gov/developers/products) and [Cloudflare DNS over HTTPS](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/).

Hosted browser checks passed for Cloudflare MX, SPF and DMARC results, NIST product identifiers, catalog filtering and mobile workspace navigation. The Supabase readiness request reported unavailable. The full test suite has 22 passing tests.
